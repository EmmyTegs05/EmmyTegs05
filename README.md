## 👨‍💻 Bio

I’m a cybersecurity professional with **4+ years of experience** across security research, security engineering, vulnerability assessment, penetration testing, security operations, and enterprise security infrastructure.

My experience spans **web and API security, network security, Linux environments, SIEM, Wazuh, IDS/IPS, EDR, firewalls, PAM, DLP, vulnerability management, and security automation**. I use **Python and Bash** to automate security workflows and scale technical assessments.

Most recently, as a **Security Researcher at the Upanzi Network, Carnegie Mellon University Africa**, I conducted security assessments across digital public infrastructure, APIs, AI-backed platforms, and web applications. I also have enterprise experience deploying and supporting security technologies for regulated banking environments.

- **Frameworks:** OWASP, NIST, CIS, MITRE ATT&CK, ISO 27001, PCI-DSS
